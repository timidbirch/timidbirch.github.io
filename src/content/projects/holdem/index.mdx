## Vesper：海岸暮色中的扑克游戏

Vesper（原 Project Holdem）是一款面向 Windows x64 与 macOS 的桌面无限注德州扑克游戏。在同一个产品里，经典模式提供离线 AI 练习与房间码私人联机，挑战模式则将扑克对局组织成有路线、目标与奖励的单人闯关。

当前采用「Coastal Lodge / 海岸木屋」美术方向：开阔海面、落日光线、胡桃木牌桌、深蓝织物台面和围桌人物共同构成场景。主菜单与大厅以亚麻装帧、黄铜细节延续氛围，从选角、入座到牌局结束形成统一体验。

## 经典模式：从双人到八人围桌

经典模式支持 **2–8 人**的全部桌容量，离线练习提供 2／3／6／8 人预设，以及 Easy、Medium、Hard 三档 AI。Hard Bot 综合位置、蒙特卡洛胜率、底池赔率、公共牌结构与筹码底池比做决策，仅使用公开信息和自身底牌。

下注控件共享整数筹码计算，提供最小、1/3、1/2、3/4、1 底池、最大等快捷档位，以及独立的合法全下操作。本人视角固定在下方，席位编号、本轮累计下注、行动焦点与持续全下标记，让多人牌桌上的信息更容易归属。

## 挑战模式：四张牌桌，一条闯关路线

挑战模式已实现由四张实际扑克桌串联的完整流程，在路线选择、目标达成与奖励之间推进，最终迎战单挑对手 **The Mirror**。它会读取最近已结束牌局的公开下注行为，为下一手调整风格；不会读取玩家隐藏底牌。

进度在安全的闯关边界保存，配有备份恢复和不兼容存档提示。经典与挑战共用纸牌、牌型评估、扑克规则和界面基础设施，通过明确的闯关与遭遇适配层扩展玩法。

## 共享规则与服务端权威联机

纯 .NET 的 `Poker.Core` 负责合法行动、下注轮次、牌型评估、主池／边池与摊牌结算，独立于 Unity 和网络层。`Poker.Protocol` 将命令、事件与快照从传输和界面实现中分离，使核心规则能够接受确定性测试。

ASP.NET Core 与 WebSocket 串联私人房间、准备大厅和牌桌串行行动队列。在线结果由服务端决定，公开状态与玩家私有信息分别下发，断线后通过快照恢复视图。公开角色外观与房间成员、实际席位身份同步。

## 从发牌到结算的完整表现

本轮美术重建覆盖重新设计的牌面与牌背、多边形桌体、七位角色各三个静态视角，以及共享的发牌、下注、摊牌和派奖反馈。主池与边池按实际赢家逐批派奖，最后显示结算凭单，区分真正赢得的筹码与未跟注退回。

弃牌、无争议获胜与摊牌参与者均可自主选择是否亮牌，默认保持不公开。中英文切换、教程、牌局历史、音量设置和独立的「减少动态」选项，补全对局之外的使用体验。

## 当前进展 · 2026 年 10 月 31 日

经典模式与挑战首版均已实现。10 月 27 日归档的 CH6 候选版本已获得用户反馈的 Windows、macOS 验收通过；近期工作聚焦海岸美术重建、席位可读性、自主亮牌和连续牌局节奏。

最新 AR2.21 记录了 **137 项 Unity EditMode 回归通过**、Windows／macOS QA 包重建，以及 Mac 原生六人、八人各连续三手的脚本检查。该记录不替代最新版 Windows 复验和真人体验反馈。角色动态暂缓，Steam 接入与公开发行仍待推进。
