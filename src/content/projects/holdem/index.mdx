## 项目想法

Project Holdem 将策略、概率、游戏工程与视觉交互结合在一起，构建支持离线 AI 练习和房间码私人联机的桌面无限注德州扑克游戏。

视觉采用原创像素风格：深青色牌桌、奶油色纸牌、彩色筹码，以及可调节的 CRT 复古显示效果。项目既关注牌局规则与状态一致性，也关注每一次发牌、下注和结算的操作反馈。

## 一套共享的扑克规则基础

将纸牌、牌堆、牌型评估、合法行动、下注轮次、底池与边池、摊牌结算封装在纯 C# 的 `Poker.Core` 中，与 Unity 和网络传输解耦。离线对战与在线服务端复用同一套规则，减少两条玩法链路之间的行为偏差。

通过 `Poker.Protocol` 统一命令、事件和快照结构，让规则层保持可测试性，让 Unity 客户端专注输入、渲染与动画表现。

## 实时联机与状态一致性

使用 ASP.NET Core 与 WebSocket 构建实时服务，串联创建房间、房间码加入、准备大厅和服务端权威牌局。每张牌桌使用串行命令队列处理玩家行动，由规则引擎校验并更新状态。

公开桌面状态与玩家私有状态分开下发，避免广播对手未公开的底牌。断线重连与快照重同步负责恢复客户端视图，牌局历史持久化则为后续回顾提供基础。

## 离线 AI 练习

提供 Easy、Medium、Hard 三种难度。Hard Bot 结合位置相关的翻前决策、蒙特卡洛胜率估计、底池赔率、公共牌结构与筹码底池比，在合法行动范围内做出决策。

AI 仅接收公开桌面信息和自身私有状态，避免依赖对手隐藏底牌。决策策略结合启发式规则与概率估计。

## 视觉系统与产品体验

Unity 客户端使用 uGUI、TextMeshPro 与 URP，围绕程序化像素纸牌、筹码、主题化控件和发牌、下注、结算反馈，建立统一的视觉系统。主菜单、联机大厅、牌桌、设置和教程共用组件与主题。

配套功能包括中英文切换、牌局历史、难度设置、显示选项和音量控制。同一个 Unity 项目面向 macOS 与 Windows x64，复用游戏逻辑与界面实现。

## 当前进展

项目已实现共享规则引擎、离线练习、私人联机、重连流程、牌局历史和像素视觉系统，并配有单元测试、多客户端集成测试与确定性模拟工具。

已有 macOS 构建与运行验收记录；Windows x64 构建已准备，实机运行验收仍待完成。Steam 接入与 Challenge Mode 属于后续计划。
