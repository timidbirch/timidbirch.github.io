## 从远程管理理解安全行为

本项目以 FZGbzuw412 发布的 MIT 协议 Python-RAT 为基础，围绕 Windows 远程管理开展安全学习实验。归档中包含客户端、服务端、Tkinter 控制面板和独立的防护原型；原始远程管理引擎保留上游归属。

实践面向受控、已授权的实验环境，关注通信、界面与行为可见性的关系。

## 客户端与服务端通信

服务端与 Windows 客户端通过 TCP Socket 交换请求与响应，涵盖系统信息查询、进程查看、文件操作与截图等管理行为，并包含可选的视频流集成。

从工程角度，连接建立、退出清理、响应处理与界面事件之间的配合，是理解这类工具的重要切入点。

## Tkinter 管理面板

图形界面提供服务启动与停止、连接信息、命令输入、常用操作和响应日志。连接与请求工作通过后台线程执行，连接结果经 Tkinter 事件调度返回主界面，减少等待网络时的界面阻塞。

## 独立的行为监测原型

`protect.py` 使用 psutil 定期检查进程名、命令行关键词和网络连接，通过 Windows 对话框提示用户，并记录允许或拒绝结果；拒绝时可终止被标记的进程。置顶状态窗口用于展示连接信息。

现有监测依赖轮询和启发式规则，未接入客户端的每次操作；注册表监控方法仍是占位实现，通用连接选择也无法可靠对应特定会话。后续需要继续完善操作级关联、注册表监控与会话归因。

## 技术栈

`Python` · `socket` · `threading` · `Tkinter` · `psutil` · `pywin32` · `Pillow` · `OpenCV / vidstream（可选）`
